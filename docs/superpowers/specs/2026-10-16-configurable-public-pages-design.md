# 公开页面管理与独立内容页设计

## 状态与边界

- 用户选择「逐页配置＋新增内容页」，不做拖拽搭建器。
- 用户随后要求「先不放大了」：**取消全站 110% 放大，保留现有字号、导航高度和页面比例**。
- 本文是第一批书面规格，等待用户审阅后进入实施计划；没有据此修改产品代码。
- 后续独立批次：SEO/可抓取公开 HTML，以及已证实的部署欠项。后续批次各自设计、计划、测试、更新文档，不把未验证项目写成完成。

## 已核实的现状

| 证据 | 现状及影响 |
| --- | --- |
| `frontend/src/views/About.vue` | 仅展示全局作者/网站资料，没有独立介绍正文 |
| `frontend/src/router/modules/home.ts`、`discover.ts`、`post.ts` | 现有公开阅读路径为首页、归档、关于、相册、搜索、标签与文章详情；无独立内容页 |
| `frontend/src/views/admin/Settings.vue` | 可配置全局品牌、主题、音乐与互动，不能逐页编辑 |
| `SiteSettingsController` / `AdminSiteSettingsController` → `SiteSettingsServiceImpl` → `SiteSettingMapper` → `SiteSetting` | 现有 KV 存储可复用；全局设置只接受白名单键、值上限 1000 字，并将全部允许键公开 |
| MySQL / SQLite / H2 的 `site_setting` | 无需新表；MySQL `setting_value` 为 TEXT，需限制序列化 UTF-8 字节数，不能只计算字符数 |
| `Navbar.vue` | 四个固定导航；新增内容页不能简单无限追加挤坏原型布局 |
| `PostDetail.vue`、`useMarkdownEnhance.ts` | 已有 Marked / DOMPurify、安全正文与阅读增强，可复用，不另造可执行 HTML 编辑器 |
| `SeoController`、`SpaController`、`frontend/index.html` | 当前 SEO 输出订阅源/站点地图，但页面初始 HTML 仍为空 SPA；本批运行时 meta 不代表完成搜索引擎可抓取改造 |

## 目标

作者不用改源码，就能独立维护 About 正文、公开页面文案和受控样式，新增介绍/项目/友链等内容页并管理导航。没有保存过配置的站点保持现有内容、品牌和视觉。

保留文章直接发布、阅读增强、匿名互动、密码相册、上传、音乐单宿主与后台权限，不恢复历史多用户社区入口。

## 1. 页面覆盖与字段

内置页面不可删除；文章、标签是模板，不为每个文章 ID 复制页面配置。404 提供可编辑说明，但始终保持未找到语义和 noindex。

| 页面 | 可编辑内容 | 可切换模块 |
| --- | --- | --- |
| 首页 | 主标题、作者上方短标签、介绍、文章列表标题；未设置时继承当前全局资料 | 介绍区、封面、作者侧栏、标签区、归档入口 |
| 关于 | 页面标题、介绍、独立 Markdown 正文 | 作者资料、网站说明、继续阅读入口 |
| 归档 | 标题、介绍 | 文章分类、汇总计数 |
| 相册 | 标题、介绍 | 相册说明、照片数量；不能绕过密码/私有相册权限 |
| 搜索 | 标题、介绍、输入提示、空状态说明 | 结果计数；搜索表单/结果本身不能被配置移除 |
| 文章详情模板 | 补充介绍；文章标题/正文仍取文章管理数据 | 封面、元信息、目录、上下篇；评论仍受全局开关和服务端权限控制 |
| 标签详情模板 | 补充介绍，标题取真实标签名 | 文章数量；结果列表仍取标签查询 |
| 404 | 标题、说明 | 返回首页/搜索入口；不能变为可收录的成功页面 |
| 新增内容页 | 页面标题、介绍、Markdown 正文 | 标题区、更新时间、继续阅读入口 |

配置采用“未覆盖/显式覆盖”的模型：缺省继承现有来源，填写后独立生效；允许清空的介绍/正文可显式设为空，不能用 `value || default` 使清空失效。恢复默认明确清除覆盖。

## 2. 受控样式

每页默认继承全站，可选择：

- 强调色：继承或 `#RRGGBB`；用于同一套语义 token，不覆盖其他页面或全局品牌。
- 背景风格：继承、纯净、柔和、纸感；均提供深色/高对比降级。
- 内容宽度：继承、窄、标准、宽；只是页面内容约束，不突破屏幕或改变固定导航。
- 内容疏密：继承、紧凑、舒展；只调内容区间距，不实施全站放大，不缩小 44px 工具触达。

不开放原始 CSS、HTML 脚本、第三方 iframe 或任意模板代码。预览样式只作用于预览根节点，离开页面不残留。

## 3. 新增内容页与发布流程

- 新页路由统一 `/pages/<slug>`；slug 为小写字母、数字、单横线，2–60 字符，创建时校验唯一。首次发布后不能改 slug，避免无重定向造成断链。
- 新页先保存草稿，明确点击发布后才对访客开放；可下线并继续编辑，再发布同一 URL。可删除自建页，需二次确认。
- 内置页面已有默认公开版本，配置草稿不影响线上；发布覆盖默认，恢复默认先进入草稿，确认发布才改变线上。内置页不提供删除/下线操作。
- 编辑页显示草稿/已发布/有未发布修改与保存时间；失败保留表单和错误原因。离开前保护未保存编辑，成功只清理对应请求快照，不覆盖请求期间的新改动。
- 草稿、发布内容分别存储；普通保存不自动发布。并行写入在当前编辑器内串行，发布前检查当前草稿版本，冲突返回明确错误让作者重新加载，不静默覆盖其他窗口。

## 4. 后台与导航

后台新增「页面管理」入口：内置模板、自建内容页两个分组；编辑区分内容、样式、SEO、预览，不把所有字段堆进原网站设置。

预览使用与公开页相同的页面配置/正文组件；支持桌面与手机预览宽度。功能页复用真实公开数据和既有加载/失败状态，不用示例文章冒充已发布内容。预览在管理员界面内，不生成公开草稿链接。

导航可为内置可导航页及已发布自建页设置名称、显示和顺序。文章/标签模板、搜索结果、404 不作为固定页直接加入导航。默认仍为首页、归档、相册、关于；桌面超出可用空间的链接进入「更多」，手机菜单显示全部，不挤压搜索、音乐和主题工具。下线/删除的自建页自动从公开导航移除，首页入口保留。

导航发布独立于页面草稿：只引用有效已发布目标，不公开草稿标题或 slug。排序需有按钮操作，不要求拖拽才能使用。

## 5. SEO 配置与后续衔接

本批支持页面 SEO 标题、描述、分享图和允许收录选项，空值从真实页面内容派生；文章/标签模板不能用固定标题替换所有文章/标签的身份。

搜索、404、后台、预览不允许通过页面配置改为 index；不把个人草稿放进导航、元数据、分享信息或站点地图。本批更新前端换页 metadata 并清理上页残留标签；服务端 HTML、完整 sitemap、规范域名及部署验收属于后续 SEO 批次。

## 6. 数据、接口与安全边界

- 新 `PageService` 管理页面，复用现有 `SiteSettingMapper`/实体，使用独立前缀；不放入全局设置白名单，不给 `getPublicSettings()` 增加草稿或大正文。
- 草稿与发布快照使用不同 KV 行，每行包含 schemaVersion、revision、时间与类型化数据。每个正文最多 10000 字符，每行序列化最多 48KiB UTF-8；名称/描述/URL 等独立校验，拒绝未知模块/样式字段与无效版本。
- 持久化更新须使用数据库条件更新实现版本比较，不依赖单 JVM 的 synchronized；未匹配当前 revision 时返回业务冲突。发布/导航变更保持事务一致。
- 管理资源位于 `/api/admin/pages` 及对应导航资源，统一 `Result<T>`、`BusinessException` 与 `ROLE_admin`；公有只读资源在 `/api/site/pages`，显式加入安全规则。
- 公开列表只给已发布配置摘要和导航，正文按单页读取。单页只能读取已发布快照；未发布/不存在页返回 404。管理接口响应不进入共享公开缓存。
- Markdown 渲染复用 Marked + DOMPurify，拒绝脚本/事件属性/不安全 URL；封面和分享图只接受现有合法站内上传路径或 http(s)，不让服务端为外链进行任意抓取。
- 不改数据库 schema，不修改用户当前数据；只在管理员明确保存/发布时写新配置。新路径 `pages` 加入后台路径保留词，已有冲突配置需给出迁移说明，不静默抢占后台路径。

## 7. 验收与文档

1. 后端先写失败测试：草稿隔离、发布/下线、默认继承、版本冲突、管理员授权、slug 冲突、未知字段和 UTF-8 上限；覆盖 MySQL 兼容查询与 H2/SQLite 行为边界。
2. 前端先写失败测试：页面配置回退/清空、各页面模块开关、Markdown 净化、编辑器真实路由离开保护、失败保存、预览不改线上、导航溢出及键盘操作。
3. 独立 SQLite 服务真实联调：修改 About → 预览 → 草稿不公开 → 发布 → 新浏览器读取；新建自建页/导航/下线/删除，不操作现有数据库或上传目录。
4. 保持至少现有前端 345 / 后端 463 测试通过；类型、Lint、构建和本轮文件格式检查通过。
5. Chrome 验证桌面/平板/320–390px 手机、深色、减少动效、键盘焦点、无横向溢出；确认未实施全站放大、原导航/单音频/密码相册仍可用。
6. 每批更新根/前后端 README、CHANGELOG 与对应使用文档，记录字段、发布流程、数据备份边界和实际验证环境。不能把前端运行时 SEO 当作搜索引擎已收录。

## 本轮不做

- 全站放大、任意拖拽搭建器、执行用户 CSS/脚本、恢复旧校园社区。
- 自动写入示例内容、改变现有作者主色、删除旧数据或改数据库结构。
- 无限历史版本、整站数据导入、邮件订阅平台或未经确认的第三方服务集成。
- 保证搜索排名/收录时间；真实域名配置和站长平台提交要在 SEO 批次明确。

## 自审

范围限定为一个可独立验收的页面管理子项目；全站缩放已明确取消。草稿公开边界、MySQL TEXT 容量、清空与继承、动态页面身份、导航溢出与路径冲突已有明确约束。没有借本批实施后续 SEO/部署架构，也没有把未验证环境写成通过。

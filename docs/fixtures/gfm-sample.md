# GFM 渲染一致性 fixture

这段话包含 **加粗**、*斜体* 与 ~~删除线~~，两侧都必须渲染成 `<del>`。

| 语言 | 用途 |
| ---- | ---- |
| Java | 后端渲染 |
| Vue  | 前端渲染 |

- [x] 已完成的任务
- [ ] 待办任务

> 引用块也必须保留。

`行内代码`、链接 [示例](https://example.com/post/1)、图片 ![配图](/uploads/sample.png) 与代码块：

```java
String value = "safe";
```

最后是一段普通段落，用于确认没有多余包裹元素。

HTML 实体也要两侧一致：`&nbsp;` 渲染成不换行空格，`&amp;` 渲染成 `&`，
`&lt;` 渲染成字面的 `<`，而不是把实体原样显示出来。

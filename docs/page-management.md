# 页面管理使用说明

后台入口为 `/<adminPath>/pages`，默认 `/admin/pages`。这是页面内容/模板管理，不取代文章、标签或相册管理。

## 修改关于页

1. 打开「页面管理」→「关于」→「编辑页面」。
2. 勾选需要覆盖的标题/介绍；不勾选时继承默认资料。介绍可以明确留空，取消该段说明。
3. 在「独立正文」中输入 Markdown。作者资料、网站说明、继续阅读入口可分别显示/隐藏。
4. 点击「保存草稿」：此时访客看到的页面不会改变。
5. 打开「预览」，选择桌面或手机。预览使用真实公开数据与同一套页面组件，草稿不放进公开 URL。
6. 确认后点击「发布页面」。有未保存修改时先保存草稿再发布。

设置、正文或请求期间的新修改不会因为旧请求成功就被当成已保存。出现版本冲突时保留当前输入；先复制需要保留的内容，再选择重新加载并合并。

## 哪些内容能修改

| 页面 | 配置范围 |
| --- | --- |
| 首页 | 介绍标题、说明、短标签、列表标题；介绍/封面/作者/标签/归档入口 |
| 关于 | 独立 Markdown 正文、标题/介绍；作者与站点资料、继续阅读 |
| 归档 | 标题/介绍、分类和文章数量 |
| 相册 | 标题/介绍、说明和照片数量；密码权限不变 |
| 搜索 | 标题/介绍、输入提示、空结果说明、数量 |
| 文章/标签详情 | 共用模板与模块开关；真实标题和正文继续走原内容管理 |
| 404 | 标题/说明、首页/搜索入口；始终不允许收录 |
| 独立内容页 | 标题/介绍/Markdown、标题区、更新时间与继续阅读 |

内置页面不能删除或下线。「恢复默认」只重置当前编辑草稿；保存并发布后才恢复线上默认。

## 新增项目/友链等内容页

在页面管理顶部填写名称和地址，例如 `my-projects`，创建后得到 `/pages/my-projects`。新页最初不公开，保存草稿不等于发布。

- 地址为 2–60 位小写字母、数字或单横线，不接受连续横线。
- 首次发布前可修改地址；首次发布后固定，包括下线后也不能改。这样不会让读者保存的旧链接无故失效。
- 下线后访客无法读取正文，公开导航自动过滤该页面；草稿仍保留，可以再次发布。
- 删除需确认，不能撤销；删除后地址可供新页面使用。不会删除文章或相册。
- 如果旧站点恰好把后台入口设为 `/pages`，先在网站设置改成其他后台路径，再创建内容页；程序不会抢占原后台入口。

## 页面样式与导航

「样式」可单独设置强调色、背景风格、内容宽度和疏密。默认继承现有主题，不改变其他页面，不实施全站 110% 缩放。没有原始 CSS/脚本输入框。

「公开导航」可编辑名称、用上移/下移按钮排序、隐藏或加入已发布页面；首页入口保留。导航有独立的「保存并发布」操作，不会发布页面草稿。最多 30 项，名称最多 20 字；较多/较长链接放入桌面「更多」，手机菜单保留全部。

预览使用同源空 `srcdoc` 容器和真实视口，直接挂载安全组件；作者正文不插入 srcdoc 字符串，不创建公开草稿链接，不放宽 X-Frame-Options。预览不会写全局主题或公开元数据；内容区停用链接与互动。

## SEO 字段的含义

可以设置页面 SEO 标题、描述、分享图和是否允许收录。留空自动从真实页面信息生成；文章/标签模板的自定义 SEO 标题是**后缀**，不会把所有详情标题改成相同文字。

搜索、404、后台与预览不允许通过配置变成可收录页面。分享图接受合法 `http(s)` 或站内 `/uploads/` 地址，不接受脚本 URL。

**本批只完善页面配置和换页时的元数据。服务端可抓取 HTML、完整站点地图与部署补齐属于后续 SEO 批次；不能据此宣称博客已经被搜索引擎收录。**

## 限制、备份和权限

- 正文最多 10000 个字符；每份序列化配置最多 48KiB UTF-8。字符未超限但大量 JSON 转义导致超过字节限制时也会拒绝，当前输入保留。
- 标题最多 120 字、介绍 1000 字；其他文字 300 字、SEO 标题 160 字、SEO 描述 400 字。
- 仅管理员可编辑草稿/导航；公开接口只读取已发布版本，列表不包含正文。
- 不新增数据库表。配置保存在已有 `site_setting` 的 `page.draft.*`、`page.published.*`、`page.slug.*` 和 `page.navigation` 键中，与全局设置白名单分开。
- 备份要保留整个数据库（包括这些键）；不要只导出网站设置接口。备份 SQLite 需要一致性快照，参照部署文档的 `.backup` 或停服备份流程。

## API 摘要

运行时路径自动带 `/api`，所有响应使用现有 `Result<T>` 信封。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/site/pages` | 已发布配置摘要与导航，不带正文 |
| `GET /api/site/pages/{id}` | 已发布单页配置 |
| `GET /api/site/pages/by-slug/{slug}` | 已发布自建内容页；未发布返回 404 |
| `GET/POST /api/admin/pages` | 管理列表 / 创建私有草稿 `{slug,title}` |
| `GET /api/admin/pages/{id}` | 读取草稿和已发布状态 |
| `PUT /api/admin/pages/{id}/draft` | 保存 `{revision,slug,config}` |
| `PUT /api/admin/pages/{id}/publication` | 发布已保存版本 `{revision}` |
| `DELETE /api/admin/pages/{id}/publication?revision=N` | 下线自建页 |
| `DELETE /api/admin/pages/{id}?revision=N` | 删除自建页 |
| `GET/PUT /api/admin/page-navigation` | 读取/保存 `{revision,items:[{pageId,label}]}` |

管理请求必须显式携带有效版本号；过期版本返回 HTTP409。未知字段、样式或模块返回400。公开页面不存在/未发布返回404，不能靠猜测草稿 ID 读取。
